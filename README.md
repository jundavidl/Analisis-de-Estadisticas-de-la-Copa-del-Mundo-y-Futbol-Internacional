# Analisis-de-Estadisticas-de-la-Copa-del-Mundo-y-Futbol-Internacional
En este repositorio se van a responder las siguientes preguntas: ¿Qué selecciones tienen el mayor promedio de goles por partido en la historia del torneo? ¿En qué fases del torneo (grupos vs. eliminatorias) se concentran más las tarjetas amarillas y rojas? ¿Qué confederación tiene el mayor porcentaje de victorias?
